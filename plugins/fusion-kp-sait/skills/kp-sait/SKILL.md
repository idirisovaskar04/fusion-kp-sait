# Сайт-КП под клиента одной командой

Вход: Instagram (@ник или ссылка), сайт, название бизнеса или 2ГИС — хоть что-то одно.
Выход: один файл `<slug>-ai.html` (всё внутри, картинки встроены — открывается в любом браузере и пересылается клиенту как файл) + скриншоты с телефона и компьютера + текст сообщения клиенту. Если у партнёра уже есть вход в Vercel (`vercel whoami` отвечает) — дополнительно выложи и дай ссылку `https://<slug>-ai.vercel.app`. Клиенту ничего не отправлять без «да» партнёра.

Эталон по уровню и структуре — `examples/bic_index.html` (BIC, недвижимость; принят Fusion AI). Другие принятые сайты: tagai-ai, urbanhotel-ai, electrocomplex-ai, kut-ai, carpoint-ai `.vercel.app`.

## 0. Перед стартом (30 секунд)
- Одной строкой ответь партнёру: «Взял(а) сайт для X, пришлю ссылку через ~40 минут».
- Заведи папку `<slug>-ai/` в рабочей папке (slug латиницей, коротко).
- **Номер на кнопках:** если партнёр назвал свой WhatsApp в запросе — ставь его; иначе номер Fusion AI 996503655933.
- **Инструменты:** Playwright для скриншотов (`npx playwright install chromium`), для вырезки товара `pip install rembg onnxruntime`. Ставь сам, ничего не спрашивая. Аккаунты не нужны.

## 1. Разведка клиента (10–15 мин) — только факты
Собери в `research.md` с источником у каждого факта:
1. **Instagram:** имя, описание профиля, ниша, город, адрес, телефон, ссылки, хайлайты (названия = их частые вопросы), 9–12 последних постов (что продают, цены, акции), комментарии под постами (что спрашивают люди). Как читать: браузер с залогиненным Instagram → иначе публичные зеркала (dumpor, picuki, imginn) → иначе Exa/web fetch. Аватар = логотип (скачай 320+ px).
2. **Сайт / 2ГИС / Google Maps:** услуги, цены, график, филиалы, отзывы (жалобы на «не дозвонился», «долго отвечают» — золото для болей).
3. **Фото:** 4–8 лучших настоящих фото клиента (товар, интерьер, команда). Мусор с фоном не берём; товар можно вырезать с фона.
4. Чего нет в источниках — **не выдумываем**. Цены, сроки, гарантии, число клиентов — только найденные. Нет цены → в примере переписки бот «уточнит у менеджера».

## 2. Боли ниши (5 мин)
- Поиск: «<ниша> <город> клиенты жалуются», отзывы конкурентов в 2ГИС, вопросы в комментариях клиента.
- Выбери **3 боли**, которые закрывает ИИ-агент (ночью никто не отвечает; одни и те же вопросы цены/адрес/график; спросил и пропал; заявки теряются в трёх мессенджерах; комментарии без ответа). Сформулируй их **словами клиента этой ниши**, не общими.
- Придумай **один пример переписки** клиента этой ниши с ботом (5–8 реплик, на русском или кыргызском — как пишут их клиенты), где бот отвечает по их реальным данным и собирает заявку.

## 3. Стиль (5 мин) — дизайнерская рука, не «ИИ-шаблон»
- Цвета — из логотипа и Instagram клиента (2 основных + нейтральный). Шрифт — **Onest** (фирменный Fusion) или один премиальный гротеск; всегда проверь ң ө ү.
- Ориентиры: 2–3 сайта сильных брендов этой ниши (Refero, Pinterest, мировые лидеры) — возьми ритм, а не копируй.
- Нельзя: нарисованные ИИ товары/интерьеры/люди, калькуляторы, длинные абзацы, мелкий серый текст, 5 разных шрифтов, эмодзи-иконки.
- Картинки: только настоящие фото клиента; генерация допустима лишь для фона-атмосферы без людей и товара.

## 4. Структура сайта (как у эталона)
Детали и тексты-шаблоны — `references/structure.md`. Порядок:
1. **Hero:** логотип клиента + «ИИ-менеджер для <клиент>», одна строка выгоды, 2 кнопки (WhatsApp / «Сколько стоит»), телефон с живым примером переписки.
2. **Цифры:** 3–4 плитки (за сколько отвечает, 24/7, языки, сколько вопросов закрывает) — только честные.
3. **Как работает:** 4–5 шагов от первого сообщения до заявки у менеджера.
4. **Раньше и теперь:** 3 их боли → что меняется.
5. **Их бизнес:** блок с их товарами/услугами/проектами и реальными фото — «бот уже знает это».
6. **Интеграции** (если есть CRM/таблицы/запись) → сразу тариф «Бизнес».
7. **Тарифы:** Старт $69/мес или $149 за 3 мес; Бизнес $129/мес или $299 за 3 мес (CRM, Google Таблицы/Календарь); внедрение $150 разово. Перепроверь актуальные цены у партнёра, если сомневаешься.
8. **CTA:** «Запускаем?» + кнопка WhatsApp. Подвал: «Fusion AI × <клиент>».
Текста мало: один заголовок + одна строка на блок. Большие фото, крупные цифры.

## 5. Сборка и выкладка
- Один `index.html` (+ `img/` webp ≤ 300 КБ каждая), без фреймворка, если не нужно. Мобильная ширина 390 px — главный экран.
- Проверка до выкладки: скриншоты 390 и 1280 (Playwright), открыть и посмотреть глазами; нет горизонтального скролла; кнопки ведут на `wa.me/<номер на кнопках>`; все факты сверены с `research.md`.
- Самокритика как арт-директор: что выглядит дёшево, «ИИ-шно», перегружено → исправить → снова скриншот. Для важного клиента — отдать субагенту-критику только ссылку/скриншоты.
- Сборка в один файл: картинки сжать в webp ≤ 200 КБ и встроить как data:URI, шрифт Onest — с Google Fonts (или встроить), итоговый файл ≤ 6 МБ. Открыть файл в Playwright на 390 и 1280, посмотреть глазами.
- Выкладка (только если есть вход в Vercel): `vercel deploy --prod --yes` из папки `<slug>-ai`, проверить живую ссылку на 390 px. Нет входа — не просить, отдать файл.

## 6. Сдача партнёру
Одним сообщением: файл сайта (и ссылка, если выкладывали), 2 скриншота (телефон/компьютер), 3 строки «что внутри», что не подтверждено (вопросы к клиенту), и готовый короткий текст для клиента отдельным сообщением. Отправка клиенту — только после «да».

## Частые ошибки (из практики)
- Выдуманные цены/гарантии → клиент ловит на первом звонке.
- Много текста (TAGAI: «много текста») → одна строка на блок.
- Непонятно «что это» (Станислав: «непонятно») → пример переписки и 3 шага простыми словами, результат, а не функции.
- Чужой логотип или перерисованный → только их настоящий.
- Сгенерированные товары/люди → «выглядит нереалистично».

## Уточнения из практики
- **Бренд-кит уже утверждён** → бери его (логотипы светлый/тёмный, цвета, шрифт, вырезки товара) и пропусти шаг 3, разведку стиля не повторяй.
- **Instagram:** читать только в режиме просмотра (Claude в Chrome / браузер с логином или публичные зеркала); ничего не лайкать, не писать, не подписываться, посты `/p/` и `/reel/` подгружаются после прокрутки. Старые сохранённые файлы проверяй: «Page Not Found» = мусор.
- **Расхождения источников** (IG пишет одно, партнёр подтвердил другое) → выписать в `research.md` разделом «Не подтверждено», на сайт не брать, вынести вопросами клиенту в сдаче.
- **Фото товара:** сырые фото с коврами и бытовым фоном в карточки не ставить — вырезать товар с фона (rembg) и положить на ровный фирменный фон с мягкой тенью.
- **Если у клиента 1–2 товара** — третьей карточкой допустимо «Доставка/шоурум/рассрочка».
- **Номер в примере переписки** — заглушка вида «0555 000 000», не реальный.
- **Выкладка (если есть Vercel):** `.vercelignore` с `research.md`, скриптами и скриншотами; папка = `<slug>-ai`. Скриншоты переснимать с живой ссылки.
- **Цены Fusion** (актуальны на 08.11.2026): Старт $69/мес или $149/3 мес; Бизнес $129/мес или $299/3 мес; внедрение $150. Сомнение → спросить партнёра.
- **Шаблон «Не подтверждено» в сдаче:** гарантия, цены остальных моделей, размеры, цвета/ткани, есть ли CRM.

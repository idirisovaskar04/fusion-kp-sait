# Партнёры Fusion: сайт-КП под клиента

Плагин для Claude Code для партнёров Fusion. Пишете «сайт для @ник_инстаграма» — Claude сам:
1. разбирает Instagram, сайт и 2ГИС клиента (только факты, без выдумок);
2. находит 3 боли его ниши и пример переписки клиента с ботом;
3. собирает сайт-КП в стиле клиента (его логотип, цвета, настоящие фото, шрифт Onest);
4. отдаёт готовый сайт одним файлом (открывается в любом браузере, можно сразу переслать клиенту) и скриншоты телефона и компьютера. Если у вас есть Vercel — ещё и выкладывает по ссылке.

Клиенту ничего не отправляется без вашего «да».

## Установка
Вставьте в чат Claude Code одну фразу:

> Установи плагин сайт-КП: запусти claude plugin marketplace add idirisovaskar04/fusion-kp-sait, потом claude plugin install fusion-kp-sait@fusion-kp-sait и скажи, когда закончишь.

Потом `/reload-plugins` или перезапуск Claude. Ничего настраивать и регистрировать не нужно.

На сайте главная кнопка «Обсудить с партнёром Fusion»: клиент пишет в WhatsApp партнёров Fusion, а в сообщении уже указано, для какой компании сайт и от какого партнёра. Хотите, чтобы клиент писал сразу вам, — добавьте в запрос: «сайт для @клиент, я Байэль, мой WhatsApp 996…».

Обновление: `/plugin marketplace update fusion-kp-sait`, потом `/reload-plugins`.
